## Historical dataset used for LEGACY cards

`docs/ref/golden_road/data.js` (third-party fan game, goldenroadlol.com) lists 73 teams, 129 team-years, 649 player-seasons and 374 players for 2011-2025. It is a **reference**: no code or UI is copied. The owner states that permission to use and adjust its rating values has been obtained (`DECISIONS.md` Q1, 03/11/2026). Coverage is thin where this game matters: VCS has one team-year (GAM Esports 2017), PCS one (PSG Talon 2021), LCP none, so those cards need `ratingSource: 'derived'`. Roster membership (who played where) should be re-verified against Wikipedia or lolesports before a LEGACY card ships.
